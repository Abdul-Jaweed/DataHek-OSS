# DataHek OSS — documentation site

A single self-contained `index.html` (no build step) documenting install,
configuration, API reference, guardrails, connectors, and operations.

## Deploy to GitHub Pages

1. Repo → **Settings → Pages** → Source: **Deploy from a branch**
2. Branch: `main` → folder: **`/docs-site`**

Or serve locally: `python -m http.server 8080 --directory docs-site`
