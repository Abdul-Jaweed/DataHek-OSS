01 // PRINCIPLES
I.

Read-Only by Construction

Write operations are rejected at the plan AST layer before any SQL is generated. The read-only guarantee is structural, not a configuration toggle.

Structural Guardrail
II.

Deterministic Verification

The LLM proposes a logical plan; deterministic schema validation checks tables, columns, dialect operators, and injection vectors against the real catalog.

Dialect AST Checks
III.

Zero Telemetry & Sovereignty

Deploy via Docker or Python on your own private network. No phone-home pings, no cloud telemetry, no analytics beacons, and no vendor lock-in.

Air-Gapped Ready
