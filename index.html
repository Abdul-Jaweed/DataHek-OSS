The problem

Your data is trapped behind dashboards and SQL

Teams wait days for answers that a database already holds. Report requests pile up, dashboards go stale, and SQL expertise becomes a bottleneck.

Dashboards answer yesterday

By the time a chart is built, the question has moved on. Ad-hoc questions fall through the cracks — or never get asked at all.

SQL is a bottleneck

Every question becomes a ticket: write the query, check it, run it, explain it. Non-technical teams stay dependent on a few experts.

Governance is an afterthought

Spreadsheet exports, ad-hoc copies, and unapproved queries blur the line between access and exposure. Nobody can see who asked what.

Features

An engine built for trust, not just answers

Every answer passes through validation, policy, and audit before it reaches you.

Natural language → SQL

Describe what you need in plain English. DataHek plans, validates, and executes the query for you.

Guardrails that bite

Read-only enforcement, SQL AST validation, injection detection, and complexity limits — structurally, not optionally.

Connect in minutes

ClickHouse, PostgreSQL, MySQL, and SQLite — managed connections, schema discovery, and health checks.

Everything is audited

Who asked, which connection, which SQL, what policy version, what result — every step is recorded and searchable.

Answers as they stream

Tokens stream while rows land as tables — no staring at spinners, no waiting for full completion.

Evaluated, always

Every release is scored against a regression dataset — validity, safety, execution, and latency.
