Features

The engine behind every answer.

Validation, guardrails, audit, and governance — not bolted on, but built into the pipeline.

Natural language

Ask questions. Get validated SQL.

Describe what you need in plain English. DataHek plans the query against your actual schema, validates every node, and only executes plans that pass structural checks.

  • ✓Schema-aware planning — no hallucinated tables or columns
  • ✓Multi-turn conversations with memory of previous answers
  • ✓Clarifying questions when the request is ambiguous

Safety

Guardrails that are structural, not optional

Write operations are rejected at the plan level — before any SQL is generated. Every query is AST-validated, scanned for injection, and bounded by complexity and timeout limits.

  • ✓Read-only enforcement across API, UI, CLI & MCP surfaces
  • ✓SQL AST validation & multi-statement rejection
  • ✓Injection detection, complexity limits, and query timeouts

Connections

Managed connections, zero plumbing

Point DataHek Cloud at your warehouse and it handles schema discovery, connection health, and secret resolution. One catalog, one permission model.

  • ✓ClickHouse, PostgreSQL, MySQL & SQLite
  • ✓Schema introspection with per-table metadata
  • ✓Connection testing and health monitoring

Governance

Every question leaves a trail

Who asked, against which connection, what SQL was planned, which policies applied, what was returned — recorded end-to-end and searchable.

  • ✓Full request → plan → execution → result lineage
  • ✓Policy refusals and masking events included
  • ✓Searchable history with retention controls

Reliability

Changes are measured, not trusted

Every model and prompt change is scored against a curated regression dataset — plan validity, safety, execution success, and latency.

  • ✓Regression suite with safety and correctness scores
  • ✓Latency and failure tracking per change
  • ✓Comparable run history
